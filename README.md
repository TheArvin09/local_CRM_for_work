# Local CRM

Локальная CRM-система для управления задачами и связанными с ними заметками.

Приложение работает через веб-интерфейс и использует **PostgreSQL** для хранения данных. Пользователь может создавать задачи, управлять их приоритетом и статусом, а также добавлять заметки.

> Проект находится в разработке. На данный момент веб-интерфейс доступен только локально.

---

## 📌 Возможности

### Задачи

Каждая задача содержит:

* `id` — уникальный идентификатор;
* `body` — текст задачи и её название;
* `priority` — приоритет;
* `status` — статус выполнения;
* `created_at` — время создания.

Доступные действия:

* создание задачи;
* просмотр всех задач;
* просмотр отдельной задачи;
* изменение данных задачи;
* изменение статуса и приоритета.

### 📝 Заметки

К каждой задаче можно добавлять заметки.

Для заметок доступны:

* создание;
* просмотр;
* редактирование.

Каждая заметка содержит время создания и последнего изменения.

---

## 🖥️ Веб-интерфейс

На главной странице отображается таблица со всеми задачами. На этой же странице можно создать новую задачу.

При выборе задачи пользователь переходит на её отдельную страницу, где отображается информация о задаче и связанные с ней заметки.
